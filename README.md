# Company Profile Digital — CV. Swarna Karya

Situs statis responsif yang disusun dari PDF company profile sumber. Semua dokumentasi portofolio menggunakan render halaman asli PDF, sehingga foto dan keterangannya dipertahankan.

## Cara preview

Buka `index.html` di peramban modern. Tidak membutuhkan instalasi atau server khusus.

## Isi paket

- `index.html` — struktur halaman
- `style.css` — tampilan responsif
- `script.js` — galeri/filter/lightbox dan navigasi seluler
- `assets/portfolio/` — render halaman PDF untuk dokumentasi
- `assets/source-company-profile.pdf` — salinan dokumen sumber

Nomor WhatsApp dan email dibuat sebagai tautan langsung berdasarkan informasi kontak dalam sumber.
